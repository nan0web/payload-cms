# 🌐 Світовий Аналіз Best Practices Інжинірингу LLM-Контексту

> [!NOTE]
> У 2024–2026 роках у галузі AI-розробки сформувався консенсус: **"Context Quality > Context Size"**. Передача всього репозиторію в модель призводить до "галюцинацій масивного контексту" (Context Degradation). Перемагає архітектура **Progressive Disclosure** (поетапного відкриття знань).

---

## 1. Як це роблять лідери індустрії

### 🏢 1. Vercel & Supabase (`llms.txt` + Sub-domain Docs)

- **Підхід:** Використовують стандарт **`llms.txt`** у корені своїх публічних репозиторіїв та сайтів документації.
- **Стратегія:** `llms.txt` грає роль "карти знань". Він не містить усього коду, а надає стисле резюме проєкту та лінки на `llms-full.txt` або конкретні розділи.
- **Результат:** Скорочення витрат токенів на 80% при опитуванні через AI CLI / API.

### 🤖 2. Anthropic & OpenAI (System Prompts + Modular Guidelines)

- **Підхід:** Відмова від одного гігантського системного промпта на користь двокомпонентної структури:
    1. _Hard Constraints (Суворі правила):_ Безпека, мова, форматування відповіді.
    2. _Tool & Workflow Specs:_ Модульні Markdown-файли, що завантажуються динамічно, коли агент викликає конкретний Tool.
- **Результат:** 99.4% дотримання формату відповідей без галюцинацій щодо відсутніх функцій.

### 💻 3. Cursor, Windsurf, Claude Code (`.cursorrules` / `AGENTS.md`)

- **Підхід:** Використання логічних редиректів та точок входу у корені проєкту (`.agents/AGENTS.md` або `.cursorrules`), які посилаються на внутрішню документацію в `docs/`.
- **Стратегія:** Репозиторій повинен бути повністю **портативним (Self-Contained)**. Жодних абсолютних шляхів до файлової системи розробника (`/Users/...`).

## 3. Ключові Переваги Нашого Підходу

> [!TIP]
> **1. Запобігання Context Rot:** Завдяки розділенню на `llms.txt` -> `AGENTS.md` -> `docs/uk/workflows/*.md`, модель отримує тільки той токенний об'єм, який необхідний для поточного завдання.
>
> **2. Автоматична CI-перевірка (`check:context`):** На відміну від більшості open-source проєктів, де `llms.txt` швидко застаріває, наш скрипт `node scripts/check-llm-context.js` миттєво виявляє незареєстровані плагіни чи воркфлоу і може оновлювати їх за один клік (`--fix`).
>
> **3. Двомовна Гармонія (Linguistic Sovereignty):** Світова практика підтверджує: мова міркувань та бізнес-наміру має відповідати команді (Українська), а назви полів, типів та коду — міжнародному стандарту (Англійська).
