# 📚 Payload CMS Workflows (`docs/en/workflows/`)

This directory contains standalone, portable guidelines for developing, testing, and releasing `@nan0web/payload-*` plugins structured within the standardized localization system (`docs/en/`).

## 🗂 Available Workflows:

1. [architechnomag](architechnomag.md) — Persona, etiquette, and response meter protocol.
2. [payload-cms-models](payload-cms-models.md) — Criteria for using and omitting schemas/models (`Model-as-Schema`).
3. [codebase](codebase.md) — Package standards (ESM, subpath exports, OLMUI, 100% TLI coverage, cross-platform compatibility).
4. [release](release.md) — Verification, installation into `testing-app`, and package releases (`pnpm pack:check` & `pnpm publish:all`).
5. [architecture](architecture.md) — Monorepo architecture, 5-plugin ecosystem interaction, and Nginx/Caddy deployment configs.
6. [pipeline](pipeline.md) — Plugin development conveyor, testing standards (`testing-app`), and the 10-point Media Migration Protocol.
