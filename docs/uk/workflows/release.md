# 🚀 Воркфлоу: Реліз та Локальне Тестування Плагінів

Цей workflow визначає кроки для підготовки, локального підключення в `testing-app` та випуску релізів плагінів Payload CMS.

## 1. Чекліст підготовки до релізу (Definition of Done)

Перед випуском нової версії плагіна виконайте наступні перевірки:

1. **Тестування:** Усі тести проходять без помилок:
   ```bash
   pnpm test
   ```
2. **Перевірка сумісності пакета:** Перевірка файлів у дистрибутиві та експортів у `package.json`:
   ```bash
   pnpm pack:check
   ```
3. **Локальне пакування:**
   ```bash
   pnpm pack:local
   ```
4. **Версіонування:** Оновіть версію в `package.json` відповідно до SemVer (наприклад, `0.1.0` -> `0.1.1`).
5. **Кросплатформенний запуск в `testing-app`:** Перевірте роботу у тестовому додатку `testing-app`.

## 2. Інтеграція з `testing-app` (Кросплатформенність)

Для кожного плагіна у `testing-app` створюється скрипт або npm-команда автоматичного підключення зі згенерованого `.tgz` архіву.

Скрипти інсталяції повинні підтримувати як Windows, так і POSIX систем (macOS/Linux) та використовувати відносні шляхи.
