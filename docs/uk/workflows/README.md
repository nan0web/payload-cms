# 📚 Робочі Інструкції Payload CMS (`docs/uk/workflows/`)

У цьому каталозі зібрано автономні, портативні інструкції для розробки, тестування та релізу плагінів `@nan0web/payload-*` у стандартизованій структурі локалізації (`docs/uk/`).

## 🗂 Список доступних workflows:

1. [architechnomag](architechnomag.md) — Персона, етикет та ритуал відповіді.
2. [payload-cms-models](payload-cms-models.md) — Критерії використання та невикористання моделей (`Model-as-Schema`).
3. [codebase](codebase.md) — Стандарти структури пакетів (ESM, subpath exports, OLMUI, кросплатформенність).
4. [release](release.md) — Перевірка, інсталяція в `testing-app` та випуск релізів (`pnpm pack:check`).
5. [architecture](architecture.md) — Архітектура монорепозиторію, взаємодія 5 плагінів та налаштування Caddy/Nginx.
6. [pipeline](pipeline.md) — Конвеєр розробки плагінів, регламент тестування у `testing-app` та 10-пунктовий протокол міграції медіа.
