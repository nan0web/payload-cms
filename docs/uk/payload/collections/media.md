# Інструкція: Колекція Media (Медіа-файли)

Цей розділ призначений для завантаження, систематизації та перегляду медіа-файлів у вашій системі.

## Можливості плагінів для Медіа

1. **Режим перегляду за папками (`Browse by folder`)**:
   - У верхньому правому кутку таблиці оберіть перемикач **By Folder**.
   - Переглядайте структуроване дерево папок (`images`, `2026` тощо).
   - Клік на ярлик папки автоматично фільтрує вміст за цим каталогом.

2. **Фізичне розташування та оптимізація (`payload-self-storage`)**:
   - При завантаженні або виборі папки файл оптимізується у WebP.
   - Файл фізично зберігається у відповідній піддиректорії на диску (`storage/<назва_папки>/<назва_файлу>.webp`).

3. **Гарячі клавіші**:
   - Натисніть `⌘/` або `Ctrl+/` для виклику цієї довідки у будь-який момент.
