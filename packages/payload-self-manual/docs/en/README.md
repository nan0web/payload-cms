# @nan0web/payload-self-manual

In-admin contextual Markdown manual and documentation system for Payload CMS.

## Keyboard Shortcuts
- `⌘ /` or `Ctrl + /` — Toggle help modal
- `Esc` — Close help modal

## Features
- **Sidebar & Search**: Instant document navigation and full-text search.
- **Mermaid Support**: Flowcharts and diagrams inside Markdown.
- **Multi-language**: N-locale support (`docs/{locale}/README.md`).
