# Dashboard Overview

Welcome to the Payload CMS administration panel.

## Getting Started

This is the main dashboard where you can:
- View recent activity
- Access all collections
- Manage your content
- Configure system settings

## Quick Actions

- **Create new content**: Use the "Create" button in the header
- **Search**: Use the search bar to find existing content
- **Navigation**: Use the sidebar to navigate between collections

## Keyboard Shortcuts

- `⌘ /` or `Ctrl + /` - Toggle help (this modal)
- `Esc` - Close current modal
- `⌘ K` or `Ctrl + K` - Quick search

## Need Help?

This help system provides contextual documentation for all Payload CMS features. Use the sidebar to browse available guides or use the search function to find specific information.
