# Огляд панелі керування

Ласкаво просимо до адмін-панелі Payload CMS.

## Початок роботи

Це головна панель керування, де ви можете:
- Переглядати останню активність
- Доступатися до всіх колекцій
- Керувати своїм контентом
- Налаштовувати системні параметри

## Швидкі дії

- **Створити новий контент**: Використовуйте кнопку "Створити" у заголовку
- **Пошук**: Використовуйте рядок пошуку для знаходження існуючого контенту
- **Навігація**: Використовуйте бічне меню для переходу між колекціями

## Гарячі клавіші

- `⌘ /` або `Ctrl + /` - Перемикати довідку (це вікно)
- `Esc` - Закрити поточне вікно
- `⌘ K` або `Ctrl + K` - Швидкий пошук

## Потрібна допомога?

Ця система довідки надає контекстну документацію для всіх функцій Payload CMS. Використовуйте бічне меню для перегляду доступних гідів або функцію пошуку для знаходження конкретної інформації.
