# @nan0web/payload-self-manual

Вбудована контекстна довідка у форматі Markdown для Payload CMS.

## Гарячі клавіші
- `⌘ /` або `Ctrl + /` — Відкрити / закрити довідку
- `Esc` — Закрити модальне вікно довідки

## Можливості
- **Сайдбар та Пошук**: Навігація по статтях та пошук за текстом.
- **Підтримка Mermaid**: Інтерактивні блок-схеми та діаграми.
- **Багатомовність**: Підтримка N-локалей (`docs/{locale}/README.md`).
