# @nan0web/payload-self-manual — Беклог задач

## 📋 Задача 3: Відображення списку підключених плагінів та версій

### Контекст та Проблема
В адмін-панелі Payload CMS наразі відсутнє єдине місце, де розробник або адміністратор може швидко побачити повний список підключених плагінів, їхні активні параметри та версії пакетів платформи.

### Вимоги до реалізації:
1. **Розділ / Вкладка в мануалі**:
   - Додати в плагін `@nan0web/payload-self-manual` окрему вкладку/розділ «Екосистема та Плагіни» (System / Plugins Info).
2. **Інтроспекція конфігурації**:
   - Автоматично зчитувати та виводити список активних плагінів із `payload.config.ts`.
   - Відображати версії підключених пакетів `@nan0web/payload-*` та статус інтеграції.
3. **Локалізація та стилістика**:
   - Підтримка перекладів опису плагінів (`uk` / `en`).
