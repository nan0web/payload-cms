# @nan0web/payload-browse-by-folder — Беклог задач

## 📋 Задача 2: Інтеграція дерева папок у стандартний акордеон навігації

### Контекст та Проблема
Зараз перехід до режиму «Переглянути за папками» реалізовано як окремий/чужорідний елемент або кнопку в інтерфейсі, замість того, щоб бути природною частиною бічного меню Admin UI.

### Вимоги до реалізації:
1. **Інтеграція в меню**:
   - Інтегрувати дерево віртуальних папок безпосередньо у стандартний акордеон бічного меню Payload (поряд із пунктом «Медіабібліотека» або всередині групи Collections).
2. **Стилістика та канонічні іконки**:
   - Використати канонічні іконки папок/колекцій з екосистеми `@nan0web/icons` (або адаптовані під брендинг).
   - Забезпечити нативні класи та поведінку розгортання/згортання Payload 3.x Admin.
3. **Стабільність підсвічування активного шляху**:
   - При виборі конкретної папки активний пункт меню має коректно підсвічуватись, зберігаючи контекст навігації.
