# @nan0web/payload-self-storage

Self-hosted storage engine for Payload CMS with physical directory placement, WebP conversion, and streaming backup/restore.

## Key Features
- **Physical Folder Layout**: Media is placed in `storage/<folder>/<filename>.webp`.
- **Payload 3.87 Compatibility**: Seamless file routing for thumbnails and upload views without 500 errors.
- **Auto Alt Tagging**: Uses clean filename as fallback alt text.
