# Колекція Media (`media`) & Self Storage

Колекція **Media** забезпечує зберігання завантажених файлів, генерацію мініатюр та оптимізовану інтеграцію із файловою системою через плагін `@nan0web/payload-self-storage`.

## Можливості та правила збереження (v0.2.0)

### 1. Збереження у фізичні вкладені папки
- **За полем `sourcePath`**: Якщо при створенні або завантаженні вказано шлях (наприклад, `img/products/cards/Visa-Instant.webp` або `docs/contracts/agreement.pdf`), файл фізично зберігається у директорії `storage/img/products/cards/Visa-Instant.webp`.
- **За ієрархією папок (`payload-folders`)**: Якщо `sourcePath` не вказано, файл автоматично розміщується у вкладені фізичні каталоги відповідно до обраної віртуальної папки Payload (наприклад, `storage/2026/news/hero.webp`).
- **Корінь сховища**: Якщо `sourcePath` і папка не задані, файл зберігається в `storage/<filename>.<ext>`.

### 2. Каскадна дедуплікація (Розмір + SHA-256 Хеш)
Плагін запобігає появі зайвих дублікатів та автозгенерованих суфіксів (`-1`, `-2`):
1. **Перевірка існування**: Перевіряється цільовий шлях на диску.
2. **Порівняння розміру**: Якщо файл існує, миттєво звіряється `stat.size`.
3. **Порівняння хешу**: Якщо розміри однакові, рахується та порівнюється потоковий SHA-256 хеш.
4. **Маркування дубліката**: Якщо знайдено ідентичний файл, тимчасовий дублікат видаляється, файл зв'язується з канонічним шляхом на диску, а в адмінці вмикається прапорець **`isDuplicate`** із поясненням у полі **`duplicateMessage`**.

### 3. Формати та розширення
- Зображення автоматично конвертуються у формат `.webp` за наявності опції `convertImageSizesToWebp: true`.
- Нерастрові та інші типи документів (`.pdf`, `.svg`, `.zip`, `.mp4` тощо) зберігають своє оригінальне розширення та MIME-тип без змін.

## Поля колекції

| Поле | Тип | Опис |
| :--- | :--- | :--- |
| `sourcePath` | `text` | Відносний фізичний шлях для збереження (наприклад, `img/cards/visa.png`) |
| `isDuplicate` | `checkbox` (readOnly) | Позначає, що завантажений файл ідентичний існуючому в сховищі |
| `duplicateMessage` | `text` (readOnly) | Повідомлення про знайдений дублікат та його канонічний URL |
| `alt` | `text` | Текстовий опис для доступності (автозаповнюється з назви файлу, якщо пустий) |
| `caption` | `richText` | Підпис або супровідний опис до медіа-файлу |
| `url` | `text` | Канонічний URL файлу (наприклад, `/media/img/cards/visa.webp`) |
| `filename` | `text` | Відносний канонічний шлях або назва файлу в системі |

## Швидкі клавіші
- **`Cmd + /`** (macOS) або **`Ctrl + /`** (Windows/Linux) — відкрити цю панель довідки у будь-який момент.
