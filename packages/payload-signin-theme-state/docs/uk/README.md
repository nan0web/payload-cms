# @nan0web/payload-signin-theme-state

Плагін зберігає обрану темну або світлу тему в адмін-панелі Payload CMS та усуває білий спалах при вході (Zero-Flicker Theme Engine).

## Основні переваги
- **Відсутність спалаху**: Миттєве застосування фону `#0f0f10` ще до гідрації React.
- **Синхронізація теми**: Автоматичне збереження вибору у `localStorage`.
